# 简历资料自动填写

运行 `npm install` 后启动 `node dashboard/server.js`，在看板左下角点击“简历资料 / 自动填写”。需要本机 Microsoft Edge；自动化使用单独的浏览器登录目录。基础看板不依赖 Playwright，自动填写需要 optionalDependencies 中的 Playwright。

1. 请 Agent 从简历提取资料到本地 `config/candidate_profile.json`，或在看板中填写。更换附件不会自动重新提取资料。
2. 核对并保存资料。留空的日期、学位等不会猜测。附件仅支持 5MB 内 PDF。
3. 粘贴优必选校园招聘详情链接，确认向公司填写资料，然后打开申请表。若需上传附件，勾选上传选项；官网解析可能改写已有内容。
4. 在独立 Edge 中登录，回到看板点击“继续填写”。上传后等待官网解析完成，再次继续。
5. 查看每字段结果，在官网补齐缺失项并检查所有内容，最后自行提交。

当前适配范围：`ubtrobot.zhiye.com` 的北森 Phoenix 申请表，包括基本信息、教育、实习、项目、荣誉。年月控件支持 YYYY-MM；籍贯、完整出生日期、照片、证书、语言能力等需手动处理。已有值保留，结果中的“保留原值”需要核对；不会点击暂存、预览或提交，也不会修改岗位投递状态。网页结构变化会报告手动处理或失败，不会尝试猜测选项。

资料、PDF 和浏览器登录信息均保存在已被 Git 忽略的 `config/` 中；不会上传到模型服务。上传和填写时会向目标招聘官网发送资料，官网可能自动保存。接口仅允许本地同源访问，写入还需要会话令牌。

验证：`node test/autofill-test.js`（需要 Edge 和 Playwright）；`node test/smoke-test.js`。
